# 🛡️ مُنقِذ | Munqith

> **أداة ويندوز خفيفة جداً لتحويل النص المكتوب بتخطيط كيبورد خاطئ تلقائياً بضغطة زر واحدة (Ctrl + Q / Alt + Q) وفي أي مكان على الجهاز!**
> 
> *Lightweight Windows utility to instantly fix text typed with the wrong keyboard layout everywhere.*

---

## 🚀 ملخص الأداة (To The Point)

هل كتبت جملة طويلة بالكامل ثم اكتشفت أن الكيبورد كان على اللغة الإنجليزية بدلاً من العربية (أو العكس) وظهرت الجملة بهذا الشكل: `hgf,hfm ,hpim`؟

**مُنقِذ (Munqith)** يحل هذه المشكلة فوراً على مستوى النظام بالكامل!

### ✨ أهم المميزات:
1. **يعمل في جميع البرامج والملفات والمتصفحات:** ليس مجرد إضافة متصفح، بل يعمل على النظام بالكامل (Word, VS Code, Browser, File Explorer, Notepad... إلخ).
2. **تحويل تلقائي وثنائي الاتجاه (EN ↔ AR):** يكتشف لغة النص المحول تلقائياً ويقلب الأحرف للاتجاه الصحيح.
3. **تراجع ذكي (Undo):** إذا حولت النص بالخطأ، اضغط نفس الاختصار مرة أخرى ليعود النص لطبيعته فوراً.
4. **شاشة إحصائيات متكاملة (مستوحاة من إضافة شقلب):** تحسب لك:
   - كم مرة أنقذك البرنامج.
   - إجمالي عدد الأحرف والكلمات التي تم تصحيحها.
   - الوقت التقديري المستقطع والمُوفَّر من إعادة الكتابة.
5. **الكشف الذكي (Smart Detection - اختياري):** إمكانية الحفاظ على الكلمات الإنجليزية الصحيحة داخل الجملة وتحويل الحروف المكتوبة بالخطأ فقط.
6. **خفيف جداً ويعمل في الخلفية (System Tray):** يستهلك ذاكرة ودورة معالج لا تُذكر ويفتح مع بدء تشغيل الويندوز تلقائياً.
7. **واجهة مودرن (Windows 11 Style):** دعم كامل للغة العربية والإنجليزية والوضع الليلي (Dark Mode).

## 📦 التثبيت والتحميل (Download & Usage)

1. اذهب لصفحة **[Releases](https://github.com/your-username/Munqith/releases)** ونزّل ملف `Munqith.exe`.
2. شغل الملف مباشرة (لا يحتاج أي خطوات تثبيت!).
3. ستظهر أيقونة البرنامج في شريط المهام (System Tray) بجانب الساعة.

### 💡 ملاحظة حول حجم الملف (~60MB):
تم بناء البرنامج باستخدام **.NET 8 (LTS)** وتم تضمين بيئة التشغيل بالكامل داخل ملف الـ EXE (Self-contained) حتى **يعمل فوراً على أي جهاز ويندوز بدون الحاجة لتثبيت .NET Runtime أو أي برامج إضافية**.

## ⌨️ كيف تستخدم مُنقِذ؟

* **الطريقة الأساسية (نص محدد):** حدد النص الخاطئ واضغط `Ctrl + Q` أو `Alt + Q`.
* **التراجع:** اضغط `Ctrl + Q` مرة أخرى على النص المحول لإعادته للنص الأصلي.
* **تخصيص الإعدادات:** اضغط دبل كليك على أيقونة البرنامج في الـ System Tray لفتح نافذة الإعدادات والتخصيص.

## 🛠️ التكنولوجيا المستخدمة (Tech Stack)

* **Language & Framework:** C# / .NET 8.0 (LTS) - WinForms
* **APIs:** Win32 Native APIs (`RegisterHotKey`, `SendInput`, `GetForegroundWindow`)
* **Design:** Clean Minimal Windows 11 Design with Light/Dark theme & Arabic/English RTL/LTR support.
